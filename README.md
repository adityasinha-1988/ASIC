🚀 Artificial Intelligence & Soft Computing (AISC) - Interactive Portal

Welcome to the AISC Interactive Course Portal, a centralized hub designed for B.Tech Computer Science students to visualize, interact with, and deeply understand core Artificial Intelligence algorithms.

Instead of just reading about algorithms, this portal allows students to watch them execute step-by-step, adjust parameters, and see the mathematics unfold in real-time.

📖 Overview

This project serves as a modern, sci-fi-themed dashboard that links together various standalone HTML-based AI visualizers. It is built to make learning AI highly engaging, intuitive, and visually appealing.

The portal covers a wide breadth of AI concepts ranging from classical search strategies to advanced optimization and game-playing agents.

🛠️ Modules Included

The portal categorizes 12 interactive visualizers into three main domains:

🔍 Search Algorithms

Uninformed Search Visualizer (ai_UnInformed_search_visualizer.html) - Demonstrates fundamental pathfinding algorithms (BFS, DFS, UCS) without heuristic guidance.

Informed Search Visualizer (InformedSearch.html) - Interactive A* (A-Star) and Greedy Best-First Search implementations.

AO Search Algorithm* (ao.html) - AND-OR graph search visualizer for problem-reduction scenarios.

📈 Optimization Algorithms (Local Search)

Hill Climbing (hillClimb.html) - Demonstrates the basic local search algorithm and the problem of getting stuck in local maxima.

Hill Climbing Variants (HillClimbingVariants.html) - Explores Stochastic, First-choice, and Random-restart variations in 3D.

Hill Climb Quest (HillClimbQuest.html) - A gamified scenario based on Hill Climbing mechanics.

Simulated Annealing (SimulatedAnnealing.html) - Live 3D visualizer showing how temperature affects the probability of accepting bad moves to escape local optima.

Annealing Bad Moves Breakdown (Annealing_Badmoves.html) - Detailed mathematical breakdown of the Simulated Annealing acceptance probability function.

N-Queens Simulated Annealing (NQueens_Simulated.html) - Solving the classic 8-Queens problem mapped dynamically to an optimization landscape.

🎮 Game Playing & Logic

Alpha-Beta Pruning (alpha_beta_tree_tracer.html) - Interactive game tree showing exactly how and why nodes are pruned to optimize Minimax.

Tic-Tac-Toe Minimax (tictactoe.html) - Play against an unbeatable AI agent powered by the exhaustive Minimax algorithm.

Blocks World (BlockWorld.html) - Drag and drop simulation of the classic AI planning problem with live heuristic scoring.

💻 Tech Stack

Frontend Structure: HTML5

Styling & UI: CSS3, Tailwind CSS (via CDN)

Logic & Interactivity: Vanilla JavaScript (ES6)

Typography & Icons: Google Fonts (Inter, Orbitron), FontAwesome 6

Zero Dependencies: No backend, databases, or build steps required. Everything runs locally in the browser.

🚀 How to Run

Clone or Download this repository to your local machine.

Ensure all .html files are kept together in the same main folder (as listed above).

Double-click the main portal.html (or index.html) file to open it in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).

Click on any of the module cards to launch the respective visualizer in a new tab.
